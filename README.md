# 几猫国产3A大作 V1 · Feng-3afps-demo

[在线试玩](https://jifeng-2025.github.io/Feng-3afps-demo/) · [低画质试玩](https://jifeng-2025.github.io/Feng-3afps-demo/?q=low)

从提供的 HTML 原文件部署，游戏代码未作修改。仓库公开，便于查看与研究实现。

## 运行要求

使用支持 WebGL 2 的现代浏览器。点击游戏开始按钮后启用音频与鼠标捕获；性能不足时选择低画质。

## 本地运行

直接打开 index.html，或运行 `python3 -m http.server 8080`，再访问 http://localhost:8080/ 。

## 部署

GitHub Pages 从 main 分支的根目录发布。更新 index.html 后会自动重新部署。
