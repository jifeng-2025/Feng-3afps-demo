# 几猫国产3A大作 V1 · 网页试玩

从提供的 HTML 原文件部署，游戏代码未作修改。

## 本地试玩

使用支持 WebGL 2 的浏览器打开 index.html。音频与鼠标捕获需要点击游戏开始按钮。

也可运行 `python3 -m http.server 8080`，再打开 http://localhost:8080。

## GitHub Pages 发布

将本目录文件上传到目标仓库。在 Settings → Pages 中，选择 Deploy from a branch，分支 main，目录 / (root)，保存。

发布后的地址以 GitHub Pages 设置页面显示的 URL 为准。

低性能设备可使用游戏的低画质设置，或在试玩地址末尾添加 ?q=low。

本部署不额外声明原游戏的作者或再分发许可证。
